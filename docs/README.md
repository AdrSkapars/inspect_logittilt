# Docs

A one-page documentation site for the extension, built with the same Quarto
template Inspect's own docs use (`meridianlabs-ai/inspect-docs`, vendored in
`_extensions/`), so it matches the rest of the ecosystem.

Build it with [Quarto](https://quarto.org):

```bash
quarto preview docs
```

`_include.yml` and `reference/refs.json` are generated by the template's
pre-render script and are not checked in.

Extensions in this ecosystem publish their own sites and are then listed from a
parent's docs: Petri Bloom and Petri Dish each have a site, plus a short page in
[Petri's docs](https://meridianlabs-ai.github.io/inspect_petri) linking to it.
Doing the same here means a small PR against `inspect_petri`, or asking the
Inspect maintainers whether they would take a similar listing. Not before this
package is on PyPI and the paper is on arXiv.
